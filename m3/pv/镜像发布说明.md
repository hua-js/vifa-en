## 生产部署时使用

光伏服务无需在服务器构建镜像。先按 README 配好目录、凭据和 Socket 权限，再使用 [compose.registry.yaml](compose.registry.yaml)：

```bash
docker compose -f compose.registry.yaml pull
docker compose -f compose.registry.yaml up -d --no-build vifa-pv
```

如需让原 M3 两个容器也使用此合并镜像，在原 M3 Compose 所在目录放入 [m3-image.override.yaml](m3-image.override.yaml)，部署时执行：

```bash
docker compose -f compose.yaml -f m3-image.override.yaml pull
docker compose -f compose.yaml -f m3-image.override.yaml up -d --no-build vifa-m3-worker vifa-m3-dashboard
```

以上是后续部署命令，本轮未执行。两个配置固定镜像 digest，避免标签变化造成部署内容漂移。
