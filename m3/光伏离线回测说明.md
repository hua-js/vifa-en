# 光伏功率离线回测

当前实现为ES02第一轮天气驱动回测。主候选WeatherRidge采用无截距岭回归，与昨日同刻和非负辐照比例模型同时比较。实现仅依赖现有NumPy/Pandas，入口未注册到生产服务或M4。

本轮结果在 `reports/pv_backtest_es02_20260909/光伏回测报告.md`。训练样本池1,276点、回测六天、共同评分567点；有辐照279点上Ridge MAE53.20kW，昨日同刻103.90kW，辐照比例52.25kW。Ridge RMSE更低，但未全面优于简单天气模型。

使用的是事后再分析天气，评估标识固定为 `retrospective_known_weather`。此结果不证明真实天气预报下的精度，也未自动选用某一模型发布预测。没有调整原M3/M4算法、数据库表、设备配置或项目依赖。

## 运行

在 `vifa/` 目录，使用具备NumPy/Pandas的Python 3.12执行。输入实测快照已经保存在本轮工件中，不再依赖原 `/tmp` 文件：

```bash
python3 m3/deploy/backtest-pv-history.py \
  --pv-jsonl m3/reports/pv_backtest_es02_20260909/inputs/pv_snapshot.jsonl \
  --weather-csv m3/reports/pv_backtest_es02_20260909/inputs/weather.csv \
  --import-verification m3/reports/pv_backtest_es02_20260909/inputs/weather_import_verification.json \
  --output /absolute/path/new-pv-backtest
```

输出目录必须不存在；重复运行不会覆盖已有报告。天气文件SHA必须与成功入库的验证记录一致。CLI不读取凭据，也不调用远程API。

绘图环境另需Matplotlib与中文字体，不要求把绘图依赖装进生产服务环境：

```bash
python3 m3/deploy/plot-pv-backtest.py /absolute/path/new-pv-backtest
```

绘图先核对工件SHA；已有PNG时拒绝覆盖。当前脚本查找macOS的PingFang或Arial Unicode字体，其他环境需配置可用中文字体路径。

相关验证：

```bash
python3 -m unittest tests.test_pv_weather_backtest -v
```

## 模块与边界

- `m3_worker/domain/pv_training.py`：时间和数值校验、分钟采样均值、十五分钟覆盖门槛、按字段对齐小时天气。
- `m3_worker/domain/pv_backtest.py`：固定天气特征、每折训练集RMS缩放、固定L2正则、按日滚动、同点误差和完整日电量。
- `m3/deploy/backtest-pv-history.py`：来源校验、输入和代码快照、数据集与中文报告。
- `m3/deploy/plot-pv-backtest.py`：从已保存结果绘制科学曲线和对比图。

每点至少12个有效分钟，四点合格才纳入该小时；不补零。辐照按结束标签取前一小时均值，温度等瞬时量插值到区间中点。小时天气展开不能解释为真实15分钟天气数据。

训练至少7个完整日，每日只拟合该日零点前结束的功率标签，参数和缩放单独保存。输入天气并非历史时点已获取的预报；后续接入真实预报必须另外按实际获取时间和预测提前量验证。

光伏交流额定容量、限发、停机标识尚未接入。当前只做非负截断，不假造容量上限；日发电量是采样功率积分估计，不是电能表实绩。天气采集和运行预测结果入库属于后续阶段。
