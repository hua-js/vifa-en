## 服务器连接（2026-10-10起）

SSH凭据和封装脚本在 `.local/m3/`（gitignored）：`ssh.env` 保存地址/端口/账号/密码，
`m3ssh.exp "<cmd>"` 执行普通命令，`m3sudo.exp "<cmd>"` 执行sudo命令（远端自动应答中文密码提示）。
容器内执行Python脚本用base64注入，避免引号转义：

```bash
B64=$(base64 < .local/m3/m3_queue_query.py | tr -d '\n')
.local/m3/m3sudo.exp "echo $B64 | base64 -d | sudo docker exec -i vifa-ipc158-services-prep-m3-worker-1 python -"
```

注意：`sudo` 只作用于管道第一段时后续命令会以普通用户执行，需整串包 `sh -c '...'` 并把 `sudo` 放在
`docker exec` 前；本机终端禁止 `echo 密码 | sudo -S` 模式。

## 生产布局与发布流程（2026-10-10核实）

生产机 aarch64（e606pro），compose 项目 `vifa-ipc158-services-prep`，
目录 `/userdata/holo/pyfiles/vifa-ipc-158-prep-20261009`：

- 镜像：`.env` 的 `RUNTIME_IMAGE` 按 digest 固定（回退=改回旧digest）；`backend/.env` 属于M4，不要动；
- Worker环境：`secrets/m3.env`；运行卷 `./run/m3:/run/vifa-m3`（socket、缓存库都在此）；
- compose命令带三个文件：`-f compose-services.yaml -f compose-active.override.yaml -f compose-pv-active.override.yaml`。

发布（本机Apple Silicon构建，与生产同arm64架构；`build-and-push.sh`仅限amd64且要求worktree干净，不适用）：

```bash
docker buildx build --platform linux/arm64 -f m3/deploy/Dockerfile \
  -t ccr.ccs.tencentyun.com/taidai-holobase-168/omnipower_vifa:<tag>-arm64 --push .
# 服务器：备份后更新 .env 的 RUNTIME_IMAGE digest，再
docker compose -f compose-services.yaml -f compose-active.override.yaml -f compose-pv-active.override.yaml pull m3-worker
docker compose -f compose-services.yaml -f compose-active.override.yaml -f compose-pv-active.override.yaml up -d --no-build m3-worker
```

改配置前先备份到部署目录 `backups/`。部署后验证 `/ready`（不只是 `/health`），恢复完成约6-7分钟。
重建会中断运行中任务（标记 `worker_interrupted`，不自动重跑），排队任务启动恢复后续跑；选队列空窗期操作。

## M3查询任务

```
docker exec -i vifa-m3-vifa-m3-worker-1 python - <<'PY'
import httpx
from m3.worker.config import Settings
from m3.worker.clients.http import RetryPolicy
from m3.worker.clients.nocobase_api import NocoBaseApiClient

settings = Settings.from_env()
fields = [
    "run_id", "station_id", "status", "interval_seconds",
    "forecast_start", "requested_by", "createdAt", "started_at",
]

with httpx.Client(timeout=15) as client:
    api = NocoBaseApiClient(
        str(settings.nocobase_base_url),
        settings.nocobase_api_key.get_secret_value(),
        client,
        RetryPolicy(max_attempts=1),
    )
    for status in ("queued", "running"):
        rows = api.list_records_all(
            "energy_forecast_manual_runs",
            filter={"status": status},
            fields=fields,
            sort=["-createdAt"],
        )
        print(f"{status}: {len(rows)}")
        for row in rows:
            print({key: row.get(key) for key in fields})
PY
```
