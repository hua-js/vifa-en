# M4 95–96 点有效窗口实施计划

**目标：** 用户确认“95点起上”；M4 接受从下一15分钟起点连续的95或96点，少于95点或中间有缺口仍阻断。M3不修改，仅展示/预览，不下发。

**方案：** 滚动源已有95点时直接采用，取消为了凑96点而依赖手动尾点；滚动不足95点时保留已有手动来源兼容，最终只允许完整95/96点。电价/PV按同一窗口裁取。求解器变量数与期末SOC落点由请求点数决定；来源策略版本升级，旧96点历史继续可复验。
