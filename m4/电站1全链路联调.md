## 模型配置

后续修改 [ai_selection_config.json](ai_selection_config.json)，每次启动联调重新读取，无需修改 Python 或重启页面服务。当前支持 Ollama `/api/chat` 协议；更换为不同 API 协议时需要对应适配器，不能只改 provider 字符串。参数按 [Ollama 官方 Chat API](https://docs.ollama.com/api/chat) 核对（2026-09-08）。

| 配置项 | 当前值及作用 |
|---|---|
| `enabled` | true；false 时本轮不发送模型请求 |
| `provider` | ollama；协议校验 |
| `base_url` | http://e606.hlszh.com:729；只填服务 origin，不含 `/api/chat` 或凭据 |
| `model` | qwen3.5:4b；改为服务实际提供的模型名称即可 |
| `think` | false；支持模型允许的布尔值或等级；null 则不发送此参数 |
| `request_timeout_seconds` | 120；单次网络等待上限，同时受剩余流预算限制 |
| `stream_budget_seconds` | 180；流响应总预算，超过预算的完整回答也不接受为成功 |
| `generation.temperature / seed` | 0 / 42；生成参数 |
| `generation.num_ctx / num_predict` | 4096 / 192；上下文与最大生成 token 数 |

`stream=true`、`keep_alive=0`、串行与未知完成门禁、JSON/规则/现场复核及不下发规则保持固定，不提供关闭安全校验的配置项。缺文件、重复 JSON 字段、未知字段、非法 URL/数值都直接报错，不回退旧模型；更换模型后仍需验证其结构化输出质量与耗时。

每轮保存完整 `model-config.json`，报告中保存其 SHA256；运行过程中修改配置文件不会改变已经启动的该轮参数。

## 运行方式

在项目 `vifa/` 目录运行，保持 8844 本地服务在线：

```sh
.venv/bin/python -m m4_selection.live_chain
```

默认读取上述配置并调用已授权模型。文件路径优先级：`--ai-config` → `M4_AI_CONFIG` 环境变量 → 项目默认文件。`--ollama-url` 和 `--model` 只覆盖本次运行，不回写文件；`--no-ai` 优先禁用 AI。

```sh
.venv/bin/python -m m4_selection.live_chain --ai-config /path/to/model.json
.venv/bin/python -m m4_selection.live_chain --model your-installed-model
.venv/bin/python -m m4_selection.live_chain --no-ai
```

禁用时仍检查真实输入、建模和求解，到 AI 阶段返回 `blocked_ai_configuration`。不自动调参或重试。

每次默认创建独立 `m4/run/station1-ai-chain/<UUID>/`，也可用 `--output` 指定新目录；不覆盖已有运行。`--api-base` 只允许本机 HTTP origin。退出码 0 仅表示整条链路在最后复核时成功生成 AI 选择预览，仍为 `not_dispatched`；其它阶段阻断返回 1。

## 阶段与证据

1. 读取本地调度配置和选择偏好，保留版本。
2. 读取电站 1 真实输入；不齐全则停下，不补点、不启动求解或模型。
3. 调用现有候选 API，重新取数并建模求解，保存服务器原始输入与结果。
4. 调用现有选择复核，确认当前版本和现场状态，再独立复验完整快照并提取摘要。
5. Qwen 只接收候选 ID、五项指标、比较结果及选择规则，不接收 96 点计划、柜号或上游凭据。保存请求、原始流、完成标志、原始回答和校验结果。
6. AI 选择必须符合本站规则；非法 JSON、重复字段、错快照或错候选均明确拒绝。自由理由只作模型原文记录，不作为现场事实保证。
7. AI 回答后再次实时复核候选、偏好、配置及输入；变化或过期即阻断，不能用程序答案替代模型失败。成功报告仍带原有效期，不能当作持续有效的设备指令。

传输与旧模型试验共用 `serial.lock` 和 `server-completion-unknown.json` 门禁，发送前持久记录在途状态，仅收到明确完成才清除；中断/超时后不自动重发。这个入口是本地 CLI 联调工具，页面“按偏好选择”按钮仍是既有确定性选择，不冒充 AI。
