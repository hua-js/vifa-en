# M4 页面读取 B1 离线结果

更新日期：2026-09-07。

> 后续方向已调整：默认页面改为参数维护与真实数据接入准备；本文件描述的旧离线结果路径仅通过 `?source=offline` 显式访问。当前使用方式见 `调度参数配置说明.md`。

`M4优化调度控制台-线上版.html` 默认展示 B1 离线结果。直接打开 HTML 即可，无需启动 HTTP 服务；页面内嵌经 Python 契约校验的 `orchestration-result.json` 与两个配套输入，保持单文件使用方式。页面与优化核心之间没有新增 API。

## 使用

- 默认入口或 `?source=offline`：B1 离线结果。
- 页面顶部“导入结果 JSON”：从本机选择 `M4OrchestrationResult` JSON，最大 5 MB。仅在当前页面内读取，不上传、不持久化。刷新页面重新读取内嵌样例。
- “原场景演示”或 `?source=demo`：保留原有需量逼近、光伏富余、AI 降级等演示。旧的 `?scenario=...` 链接仍进入演示模式。
- 电站、候选与时点切换只改变预览；每站独立保存预览候选，不写入 `selected_candidate_id`，不触发求解、AI 或 EMS。
- 月度账单及其抽屉仍为原演示内容，本轮未接入 B1，业务口径仍待确认。

## 字段与显示口径

| 页面 | 来源与转换 |
|---|---|
| 容量、初始 SOC、需量与功率上限 | 站级 `input_summary` |
| 96 点目标功率 | `plan[].target_power_kw` 为非负幅值；根据 `mode=charge/discharge/idle` 映射为负值充电、正值放电、零值待机 |
| SOC 曲线 | 第一点之前取摘要 `initial_soc_pct`，各时段结束取 `expected_soc_pct`，不在页面重新积分或修改优化计划 |
| 时点、时域 | 使用计划的实际时间戳，不使用浏览器时区或原演示的固定日期替代 |
| 候选成本、光伏自用、最大购电与超限 | 直接读取 `metrics`，保留 `optimal` 与 `feasible` 的区别 |
| 负荷、光伏、电价与分时色带 | 仅在站点、请求、计划起点及全部来源版本匹配内嵌配套输入时展示 |
| 购电费用差额 | 同输入、无储能的 `sum(max(0, load - pv) * buy_price * 0.25)` 减候选 `import_cost`；不含需量账单、上网收益和循环成本。缺少匹配输入时不计算 |
| 需量图 | 候选 24 小时计划购电；有匹配输入时另显示无储能参考，不能视作近 16 分钟实际计量或 EMS 削峰执行 |
| 版本与风险 | 详情展示运行、请求、模型、目标配置、计划与来源版本，以及求解状态和风险说明 |
| 选择、下发与回读 | `pending_ai / null`、`not_dispatched / null`；实际功率、偏差与回读时间为空，不绘制模拟实际功率曲线 |

原始 B1 示例输入为 Mock，数学结果来自真实优化器求解；不构成生产计划或现场收益证明。来源版本匹配依赖输入方正确更新请求及版本号，不替代内容哈希或安全复验。

## 异常处理

浏览器对展示所需的版本、状态、站点与请求归属、候选完整性、数值边界和 96 点连续时间轴进行检查。当前页面仅支持 `station-1` 与 `station-2`，不按数组顺序猜测站点。

- 单站业务失败：该站显示错误和空计划，另一站仍可预览。
- 某候选不可行、超时或失败：禁用对应候选卡片，默认预览本站首个可用候选。
- 缺少本站结果或无可用候选：展示空态，不回退为旧的 Mock 曲线。
- JSON 损坏、重复站点、错位/不足 96 点、非 B1 选择或下发状态：整份导入拒绝并清空旧曲线。
- 无法识别站点的输入错误：在全场总览列出安全输入标识和错误说明。
- 导入异步读取有代次检查，后选文件不会被先选文件的迟到结果覆盖。

浏览器校验仅服务于只读展示，不是完整 Python 契约校验，更不是设备下发安全校验。没有新增真实数据源、设备接口或生产配置。

## 更新内嵌样例

在仓库根目录，先按 `m4_orchestrator/README.md` 生成新的配套输入与输出，然后运行：

```bash
.venv/bin/python m4/tools/embed_offline_result.py
.venv/bin/python m4/tools/embed_offline_result.py --check
```

脚本先通过 `OptimizationRequest` 与 `M4OrchestrationResult` 校验，核对两站请求与来源版本，再同步 HTML 的 `script#m4-offline-bundle`。JSON 中的 `<` 转义后嵌入，避免提前终止 script 标签。无需复制 JSON 到服务器或增加外部 JS 依赖。
