# M2 线上部署流程图

更新日期：2026-08-26

## 1. 上线后的数据流程

```mermaid
flowchart TD
    A[NocoBase 页面] --> B[iframe 打开 HTML 看板]
    B --> C[请求 /energy-efficiency-api]
    C --> D[Python HTTP 服务<br/>尚未建立]

    K[服务器环境变量<br/>保存 API 地址和令牌] --> D
    D --> E[读取 t_emu:list]

    E --> F{选择场站}
    F -->|ES01| G[读取 emu11、emu12]
    F -->|ES02| H[读取 emu21～emu26<br/>光伏读取 emu27]

    G --> I[统一换算成 kW]
    H --> I
    I --> I1[市电 latest_grid_power ÷ 1000]
    I --> I2[电池 battery_power ÷ 1000]
    I --> I3[储能 = 所有柜 latest_power 之和]
    I --> I4[ES02 交流光伏 = emu27.latest_solar_power]

    I1 --> J[推算负载<br/>负载 = 市电 + 储能 + 交流光伏]
    I3 --> J
    I4 --> J

    J --> L{负载是否大于 0}
    L -->|否| M[本分钟停止计算<br/>不写入分钟效率表]
    L -->|是| N[计算三条能效链路]
    I2 --> N

    N --> O{设备时间差是否超过 120 秒}
    O -->|是| P[受影响的效率记为空<br/>不参加当日累计]
    O -->|否| Q[得到有效效率]

    P --> R[生成当前分钟记录]
    Q --> R
    R --> S[写入或更新<br/>t_efficiency_points]

    D --> T[查询今日分钟效率]
    D --> U[查询瓶颈事件<br/>t_efficiency_bottleneck_events]
    N --> V[生成实时链路结果]

    S --> T
    T --> W[组装看板 JSON]
    U --> W
    V --> W
    W --> X[HTML 显示实时链路、今日曲线和瓶颈事件]
```

## 2. 每分钟自动保存流程

```mermaid
flowchart LR
    A[每分钟定时任务<br/>尚未建立] --> B[处理 ES01]
    A --> C[处理 ES02]
    B --> D[读取 → 换算 → 计算]
    C --> E[读取 → 换算 → 计算]
    D --> F{负载有效}
    E --> G{负载有效}
    F -->|是| H[保存分钟点]
    G -->|是| H
    F -->|否| I[跳过本分钟]
    G -->|否| I
    H --> J[同场站同一分钟<br/>有则更新、无则新增]
```

## 3. 从现在到正式上线

```mermaid
flowchart TD
    A[当前状态<br/>读取、换算、计算已完成] --> B[建立 Python HTTP 服务]
    B --> C[提供 /health]
    B --> D[提供 /energy-efficiency-api]
    D --> E[让 HTML 显示真实数据]
    E --> F[真实写入一条分钟效率并读回检查]
    F --> G[建立每分钟自动任务]
    G --> H[部署到测试服务器]
    H --> I[配置 HTTPS 和反向代理]
    I --> J[NocoBase iframe 测试]
    J --> K[连续运行检查]
    K --> L{是否稳定}
    L -->|否| M[修正问题后重新检查]
    M --> K
    L -->|是| N[提交 Git 并建立上线版本]
    N --> O[更换正式令牌]
    O --> P[正式上线]
```

## 4. 上线前必须确认

- Python 服务重启后能自动恢复运行。
- API 令牌只放在服务器环境变量中，不写入 Python、HTML、Git 或网址。
- iframe 不直接接触 `t_emu` 的令牌。
- 真实测试完成“读取 `t_emu` → 计算 → 写入分钟表 → 读回 → HTML 显示”。
- 同一分钟重复执行不会产生两条数据。
- 负载小于或等于 0 时跳过，不强行写成 0。
- ES02 的设备时间差在 120 秒以内时可以正常计算。
- 上线前提交 Git，保留可以回滚的版本。
