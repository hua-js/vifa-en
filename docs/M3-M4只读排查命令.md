## 2. M3 最近预测任务与存储 Token 读取状态

```bash
cd /userdata/holo/pyfiles/vifa-m3

docker compose -f m3/deploy/compose.yaml exec -T vifa-m3-worker python - <<'PY'
import os, json, httpx

url = os.environ["M3_NOCOBASE_BASE_URL"].rstrip("/")
token = os.environ["M3_NOCOBASE_API_KEY"]

with httpx.Client(timeout=30, follow_redirects=False) as client:
    response = client.get(
        url + "/api/energy_forecast_manual_runs:list",
        headers={"Authorization": "Bearer " + token},
        params={"pageSize": 20, "sort": "-id"},
    )
    print("预测任务 HTTP:", response.status_code)
    if response.status_code == 200:
        rows = response.json().get("data", [])
        if not isinstance(rows, list):
            print("返回结构异常，data 不是列表")
        else:
            fields = (
                "id", "station_id", "run_id", "interval_seconds",
                "status", "error_code", "createdAt", "completed_at",
            )
            for row in rows:
                print(json.dumps(
                    {k: row.get(k) for k in fields},
                    ensure_ascii=False,
                ))
PY
```

HTTP 200 仅证明本次读取成功，不证明写入权限。`queued`、`running`、`succeeded`、`failed` 分别表示排队、运行、成功、失败；结合时间和 `error_code` 判断。

## 4. M4 两站输入、日计划、滚动与写表结果

在 M4 所在服务器运行：

```bash
python3 - <<'PY'
import json
from urllib.request import urlopen
from urllib.error import HTTPError

base = "http://127.0.0.1:8844/m4-api/stations"

def read(url):
    try:
        with urlopen(url, timeout=60) as response:
            return json.load(response)
    except HTTPError as exc:
        print("HTTP错误:", exc.code)
    except Exception as exc:
        print("读取失败:", type(exc).__name__)
    return None

def write_summary(value):
    if not isinstance(value, dict):
        return value
    fields = (
        "status", "run_id", "effective_at",
        "network_write_performed", "completed_operations",
        "operation_counts", "device_execution_status",
        "failure_stage", "http_status", "error_type",
        "reason", "pending_operation",
    )
    return {k: value.get(k) for k in fields}

for station in ("station-1", "station-2"):
    print("\n===", station, "===")

    inputs = read(f"{base}/{station}/daily-inputs")
    if inputs is not None:
        sources = inputs.get("sources") or {}
        request = inputs.get("request") or {}
        print(json.dumps({
            "checks": inputs.get("checks"),
            "current_soc": sources.get("current_soc"),
            "current_power": sources.get("current_power"),
            "constraints": request.get("constraints"),
            "capability": request.get("capability"),
        }, ensure_ascii=False, indent=2))

    data = read(f"{base}/{station}/daily-plan")
    if data is not None:
        rolling = data.get("rolling") or {}
        result = rolling.get("result") or {}
        print(json.dumps({
            "daily_status": data.get("status"),
            "daily_message": data.get("message"),
            "automation": data.get("automation"),
            "rolling": {
                k: rolling.get(k)
                for k in ("run_id", "status", "failed_at", "message")
            },
            "rolling_effective_at": result.get("effective_at"),
            "ems_table_write": write_summary(data.get("ems_table_write")),
            "rolling_ems_table_write":
                write_summary(result.get("ems_table_write")),
        }, ensure_ascii=False, indent=2))
PY
```

## 5. 结果判断

- 输入各项应为 `ready`，日计划和滚动分别核对是否 `completed`。
- 最新实测有效，不代表之前失败时刻的实测也有效；对照 `observed_at`、`failed_at`。
- 自动计划的 `next_check_at` 是预计检查时间，不能单独证明后台已执行。
- 写表状态 `plan_table_readback_verified` 表示计划表回读确认；同时核对 `run_id`、`effective_at`，避免把旧记录当成本次结果。
- `network_write_performed=false`、操作数0表示该次没有实际修改表，不一定是失败。
- `device_execution_status=unverified` 表示设备执行未核实，不能据此宣称设备已执行。
- 发现 `table_write_unconfirmed` 或待确认操作时，保留日志和现场记录，先核对失败阶段，不盲目清理 hold 或重复下发。
