## 目录约定

- `m1/` 能源监控；`m2/` 能效链路；Python 文件随模块，页面在各模块 `web/`，测试在各模块 `tests/`。
- `m3/worker/` 为原 `m3_worker/`；`m3/deploy/` 存放原根 Dockerfile/Compose/运行依赖；数据采集与回测脚本在 `m3/scripts/`，输入 CSV 在 `m3/data/`。
- `m4/settings/`、`optimizer/`、`orchestrator/`、`selection/` 对应原 M4 四个包；页面、网关、部署和工具分别放 `web/`、`node_red/`、`deploy/`、`scripts/`。
- `shared/styles/` 保存 M1/M2 共用主题；各模块正式说明、设计和计划统一在根 `docs/<module>/`。
- `outputs/<module>/<category>/<run-id>/` 保存回测、分析、发布及完整的调度决策证据；历史发布包内容不修改。
- `runtime/<module>/` 保存数据库、日志、Socket、锁等状态；`.local/` 保存本机凭据与本地配置，两者均忽略 Git。
- Python 命名空间同步为 `m3.worker` 与 `m4.settings` 等，不保留重复源码副本或旧包别名。
