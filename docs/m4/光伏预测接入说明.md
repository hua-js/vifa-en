# M4 只读光伏预测输入

M3负责定时或管理员手动生成光伏预测，M4通过现有NocoBase只读接口查询 `energy_pv_forecast_runs` 与 `energy_pv_forecast_points`，复用M3发布完成的批次。M4不调用生成接口，不更新天气，不训练模型，不轮询预测任务。使用原有平台凭据，两表只需list权限；不需要PV控制Socket。

## 批次与时间校验

- 只接受ES02、operational、completed的最新批次（as_of/id倒序），生成时间不得晚于查询时间。
- 单批15分钟连续96点，校验关联、时间戳、步数及有限非负功率；来源版本绑定批次、内容哈希、天气与模型信息和读取值。全天零填补另保存策略、原覆盖点数、填补点数与时间列表，并加入source_versions供记录追溯；页面图表提示按零估算。
- 全天比较按当天00:00–24:00对齐。2026-09-16确认：仅北京时间20:00–次日07:00允许窗口外缺测补零，已有预测值保留；07:00–20:00任一缺测阻断日计划，等待M3完整输入。不读取历史实测代替预测、不拼接批次。整天无重叠、整批缺失、批内缺点、损坏和读取失败继续阻断。
- 只允许今天或昨天生成的批次。日输入记录完整性版本 `pv-night-zero-20-07-v1`，站2旧版本日计划退出当前方案但保留历史；页面缓存同步失效。M3通常06:00生成06:15起的24小时预测，当天00:00–06:15的缺口可按已确认范围补零；07:00–20:00仍须完整覆盖。
- 电站1的零光伏来源保留。缺失、过期或覆盖不足时阻断新方案并提示等待M3更新；历史调度记录保留，不当作有效的新计划。
