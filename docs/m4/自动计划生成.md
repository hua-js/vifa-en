# M4 自动生成计划

2026-09-12：用户要求自动生成优化计划，取消必须点击按钮的流程。

实施：后端生命周期启动自动任务，启动后检查两站，随后按15分钟时间窗自动生成现有全天比较计划。复用数据与MAPE校验，不触发设备下发；页面关闭不影响运行。每站运行中不重复启动；自动调度使用共享目录文件锁防止多个服务进程重复调度，时间窗状态持久化避免重启重复触发。异常记录并隔离两站，下一时间窗重试。提供服务端开关M4_AUTO_PLAN_ENABLED（默认开启）供测试/调试停用，非浏览器控制。

页面从daily-plan响应取得自动生成状态，定期只读刷新；按钮改为“立即重算”作为手动调试入口。无需修改Node-RED路由白名单。当前仍为全天比较，不能称为实时SOC起点的剩余日执行计划；该能力后续单独实现。

验证：时间窗去重、跨窗触发、运行中跳过、重启持久化、两站异常隔离及多实例锁；本地服务启动后不发POST，等待自动生成并验证页面。

## 验证结果

自动任务及接口相关6项通过，网关19项通过。启动本地服务后两站生成新run_id且completed，无需浏览器POST；页面显示自动状态并读取优化方案，未出现脚本错误。记录明暗1440/834/390截图并检查桌面/手机渲染。当前未部署线上；本轮未重跑全量套件。

保持单个应用进程提供计算任务服务；多进程的自动调度通过leader锁去重，但现有手动任务状态仍在各进程内存，不在本次扩展为跨进程作业队列。服务重启时同一15分钟窗口已发起的任务不重复启动，未完成或失败任务在下一窗口重新生成。
