## 原因是分层目标允许用本时段超线换取整个窗口更低的最大峰值

最新 cost 方案顺序为：需量峰值超限 → 超限积分 → 净电费 → 光伏未吸收 → 推荐 SOC 偏离 → 吞吐量 → 凌晨谷段重排。节费优先只表示在更高层目标锁定后优化费用，并非以总账单费用统一权衡全部目标。

14:15 初始 SOC 为 48.8%，总容量配置为 522 kWh，安全下限 2%，充/放效率各 96%。14:15–17:30 的高负荷区间中，仅 16:00 有明显负荷低谷。方案在其余时段放电，把购电压在约 531.9122 kW，并在 16:00 补电；17:30 SOC 恰好降到 2%。

局部电量核算（不是重新求解）：如果把 16:00 充电限制到 504 kW 阈值内的 3.3912 kW，其他动作固定不变，则少补 6.6989 kWh 电池侧电量，17:30 SOC 将降至约 0.7167%，违反下限。若允许重分配前后放电，在该区间的电量平衡下，最大购电功率至少约为 533.8910 kW；若 16:00 完全不充电，该下界约为 534.1314 kW。此下界只核算该前缀区间，未声明求得整个计划的反事实最优解。

因此，16:00 充电虽制造该时点的超线，却降低了当前模型最先优化的全窗口峰值。用户要求的“不能通过充电主动制造超限”并没有被设为硬约束。

## 18 点的充电与 16 点不是同一个问题

17:30 SOC 达 2%，18:00 充电把 SOC 补到推荐下限 3%；18:30/18:45 继续补能。18 点这一小时总充电 56.4477 kWh，经过 96%×96% 效率后可供 52.0222 kWh 放电，恰好对应 19:00–20:45 的计划放电总量。后续放电将购电维持在 504 kW。

所以这里确实在高价补能、低价放电，作用是避免后续超需量，不是峰谷价差套利。18:00 而非同价后续时点的选择，与后续较低优先级的推荐 SOC 偏离目标相符；未做逐目标反事实求解，不把这一时点选择断言为唯一原因。
